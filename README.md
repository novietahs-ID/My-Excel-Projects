# 📊 Excel Data Analytics Project Portfolio

## 🚀 Project Overview
This project demonstrates the use of Excel to transform raw data into actionable insights through data analysis, reporting, and visualisation. The analysis focused on sales performance, customer trends, and operational metrics to support data-driven decision-making and risk-aware business planning.

## 🔍 Skills Demostrated

- Data Cleaning & Validation
- Dashboard Development
- Data Visualisation
- Trend Analysis
- Business Reporting
- Risk & Performance Insights

## 🛠️ Tools & Technologies

- Microsoft Excel
- PivotTables
- Pivot Charts
- Lookup Functions (VLOOKUP)

## 📂 Projects

### 🚲 Bike Sales Analysis
Analysed customer and sales data to identify purchasing trends and key performance indicators.

### 🌪️ Atlantic Hurricane Analysis
Explored historical hurricane data to identify trends, patterns, and potential risk insights.

### 🏥 NHS Workforce Analysis
Analysed workforce data to support reporting and operational insights.

## 🎯 Key Outcomes
•	Transformed raw data into actionable business intelligence
•	Strengthened analytical thinking and problem-solving capabilities
•	Improved reporting efficiency and insight generation
•	Developed practical experience in data-driven decision support
